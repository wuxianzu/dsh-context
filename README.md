# DSH 上下文（公开对话归档）

用于给 DeepSeek Harness 喂长上下文的公开仓库：存放**脱敏后**的会话记录、决策日志与交接笔记。

## 目录约定

- `logs/` —— 按日期归档的对话记录（`YYYY-MM-DD-主题.md`）
- `decisions/` —— 关键决策与理由（ADR 风格，一条一个文件）
- `handoff/` —— 会话交接笔记（下次开工先读这个）
- `notes/` —— 零散事实、结论、待办

## 写入规则

1. **先脱敏再提交**：路径、账号、token、机器信息一律不进仓库。
2. 一条记录一个文件，文件名可读；正文第一行写结论。
3. 追加而非覆盖：历史记录只增不改。
